## 0.1.0 (2026-09-28)

First public release. CouchSpire runs a real two-player Slay the Spire 2 multiplayer run in one
game, on one screen, with no networking.

### Added
- Couch co-op: per-controller seats, each controller drives its own character, and a
  press-to-take-over control switch. See `docs/couch-coop.md`.
- Simultaneous play in combat: the teammate who isn't driving can play cards, end their turn,
  and answer choices without taking the screen.
- A teammate UI built from the game's own art: P2's top-bar section, relic row, hand, health
  bar, and rewards/event/rest-site/shop/treasure handling, all per-character.
- Per-character decks, gold, potions, relics and choices; rewards, shops, rest sites, treasure
  and events are all handled per player instead of mirrored or shared.
- A shared right-hand column for P2's rest-site, treasure, shop, rewards and out-of-combat
  card-picker panels, sized off P1's own on-screen buttons so it never overlaps them.
- `CouchSpire.cfg` settings file (see `CouchSpire.cfg.example`), and `deploy.sh` for macOS and
  Linux (including Steam Deck/Bazzite Game Mode) installs.
- Steam Deck / Bazzite Game Mode support: the mod treats the game window as focused under
  gamescope unless the Steam overlay is open, so the controller works from launch.
- Pure code mod: `has_dll=true`, `has_pck=false` — no asset pack to install.

### Changed
- Couch co-op is always two players. The multiplayer host menu's **Couch Co-op** card starts a
  run and adds P2 automatically.
- Player-facing text is English only.

Based on Local Multi-Control (DualRoleAdventure) by liwenhao0427 and GuyGinat — see the
Credits section of `README.md`.
